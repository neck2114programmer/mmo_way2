# Эльдория: Клинки Рассвета (Next.js + PostgreSQL)

Браузерная MMORPG-витрина (Three.js, процедурные 3D-модели) с настоящим backend:
регистрация/вход (Argon2id, cookie-сессии), герои и их внешность в PostgreSQL, события мира на сервере.

Исходная игра (`neck2114programmer/mmo_way2`) была чисто клиентским Vite-SPA без сервера и аккаунтов.
Весь её код (`src/game`, `src/ui`) перенесён без смены движка (Three.js 0.170, процедурные модели).
Оригинал остаётся в git-истории исходного репозитория; старых аккаунтов/сохранений там не было, переносить из него нечего.

## Стек
Next.js 16 (App Router) • React 19 • Three.js • PostgreSQL 16 • Drizzle ORM • Argon2id (`@node-rs/argon2`) • Tailwind 4 • Vitest

## Быстрый старт (локально)
```bash
cp .env.example .env            # впишите свой DATABASE_URL
export POSTGRES_PASSWORD=...    # тот же пароль, что в DATABASE_URL
docker compose up -d db         # PostgreSQL (или используйте свой сервер)
npm ci
npx drizzle-kit migrate         # применить миграции (неразрушающие; также применяются при старте сервера)
npm run dev                     # http://localhost:3000
```
Без Docker: создайте БД и пользователя вручную (см. `docs/SERVER_INSTALL.md`, шаг 2).

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | строка подключения PostgreSQL (только сервер) |
| `ADMIN_LOGINS` | логины-администраторы через запятую (служебные кнопки событий на карте) |
| `COOKIE_SECURE` | `true`/`false` — принудительный флаг Secure; по умолчанию по протоколу запроса (https → Secure) |

## Маршруты
- Страницы: `/login`, `/register`, `/game` (защищена; без входа → `/login`), `/` → перенаправление.
- API: `POST /api/auth/register|login|logout`, `GET /api/auth/me`,
  `GET/POST /api/characters`, `PATCH/DELETE /api/characters/:id`, `POST /api/characters/:id/select`,
  `GET/POST /api/world` (снимок событий / служебные действия админа), `GET /api/health`.

## База данных
Таблицы (миграция `drizzle/0000_init_accounts_characters.sql`, идемпотентная):
- `accounts` — логин + нормализованный логин (UNIQUE), `password_hash` (Argon2id), даты.
- `sessions` — SHA-256 токена (сам токен только в HttpOnly-cookie), срок жизни 14 дней, FK → accounts (CASCADE).
- `characters` — FK → accounts (CASCADE), имя (UNIQUE без учёта регистра), класс, пол, `hair_id`, `appearance` JSONB, тиры, даты, `last_played_at`; CHECK-ограничения.
- `auth_attempts` — счётчики для ограничения частоты входа/регистрации (общие для всех процессов).

Миграции: `npx drizzle-kit generate` (после правки `src/db/schema.ts`) → `npx drizzle-kit migrate`. Сервер при старте сам применяет
неприменённые миграции (`src/instrumentation.ts`); команд сброса/удаления таблиц нигде нет.

## Причёски и внешность — как устроено
- `src/game/data/hair.ts` — каталог: стабильный `id` (`short_crop`, `twin_tails`, …), поддерживаемые риги (`humanoid_m/f`) и типы головы (`head_m/f`),
  параметры посадки, правила для шляпы/капюшона/шлема/короны/рогов, запасная причёска.
- Индекс модели (`style`) нужен только рендереру и **не хранится**. В БД лежит `hairId` конкретного героя.
- `src/game/appearance.ts` — серверная (и клиентская) нормализация: белый список полей, диапазоны, цвета `#rrggbb`, совместимость причёски
  с полом/головой *этого* героя. Несовместимая причёска заменяется запасной, остальные настройки сохраняются; старый числовой индекс переводится в id.
- При чтении героев данные снова нормализуются, а исправленные сохраняются обратно (самовосстановление).
- Редактор показывает только совместимые причёски; случайная внешность выбирает только совместимые.

## Безопасность
Argon2id; сессионный токен — 256 бит, в БД только хэш; cookie `HttpOnly`, `SameSite=Lax`, `Secure` по https; проверка Origin/Sec-Fetch-Site на всех
изменяющих запросах (CSRF); ограничение частоты (вход: 8 неудач/15 мин на логин и 40 на IP; регистрация: 10/час на IP); параметризованные запросы Drizzle;
пароли/токены не логируются; ошибки БД наружу не раскрываются (понятное сообщение 503, если БД недоступна). Если сервер стоит за прокси, он должен передавать
`X-Forwarded-For`, `X-Forwarded-Proto`, `Host`.

## Тесты
```bash
npx vitest run     # 20 тестов; интеграционные используют отдельную БД app_db_test (создаётся автоматически)
npx tsc --noEmit && npm run build
```
Покрыто: Argon2id и неверный пароль, уникальность логина, rate-limit, привязка причёски к герою и сохранение, исправление женской причёски у мужского героя,
изоляция аккаунтов, лимит героев и уникальность имён, каскад FK, правила причёска+головной убор, состояния событий (старт, перемещение охотника, победа/провал, исчезновение),
целостность классов/умений/клипов и локаций/порталов.

## Что не сделано / ограничения
